# Shamba Direct - Agribusiness E-Commerce
Framework: PHP 8.2 + MySQL + HTML/CSS/JS. Same language as Laravel (PHP).
Features: Farmer/Buyer/Admin, Catalogue, Search, Cart, Checkout, Receipt.
Setup:
1. Import database.sql in phpMyAdmin
2. Copy config.example.php to config.php and set DB credentials
3. Run: http://localhost/agribusiness/
Live URL: https://shamba-direct.infinityfreeapp.com
